# Island Forge — FiveM Island Creator

Island Forge is a browser-based procedural terrain editor inspired by the source workflow supplied for GunWare Island Creator. It uses Three.js for the live 3D viewport and a seeded terrain pipeline for repeatable island generation.

## Editor features

### Procedural generation
- Nine landforms: round, long, crescent, twin islands, archipelago, atoll, volcano, continent and scattered islands.
- World sizes from 512 m to 16,384 m.
- Seeded simplex noise, multi-octave FBM, ridged mountain noise, domain warp and organic coastline breakup.
- Height normalization, beach shelf shaping, sea-floor undulation, hydraulic erosion and thermal erosion.
- Slope/height-based sand, grass, rock and dirt blending.
- Grid-based deterministic placement for trees, rocks and grass to avoid the old random-dot distribution.
- Resolution and cell-size choices constrained by world size.

### Sculpt and test
- Raise, lower, smooth, flatten, material paint, erase, remove vegetation and add vegetation brushes.
- Brush radius/strength, undo and redo.
- Orbit/top-down views, time-of-day lighting, animated water with depth/fresnel response.
- Walk mode with movement, sprint, slow walk, jump and first-/third-person camera.
- Display modes, layer visibility, grid and chunk overlays.
- Tropical palms rendered with vertical trunks and radial fronds.

### GunWare material library
- The four terrain slots now select from the GunWare material names found in the supplied source bundle.
- Each selected material includes its diffuse and normal GTA texture dictionary names, preview tint and collision-material index.
- Preview shading uses material-specific tints and procedural detail; the previous flat dark color output is fixed with the proper Three.js tone-mapping and color-space shader chunks.
- Source export creates tileable procedural PNG fallback maps for Blender and references the GunWare texture names in the materials manifest.

**Texture note:** the supplied reference contains GTA texture dictionary names, not the actual diffuse/normal image files. The fallback PNG maps in this package are generated by Island Forge and are not copied or represented as original GunWare/GTA bitmap assets. For a native YTD, the Windows worker must resolve the named textures from the matching game archives with the appropriate tools, or use an explicit replacement texture set.

### Surface and GTA placement
- Four independently selectable material slots: sand, grass, rock and dirt.
- Grass, tree and rock density/type controls.
- GTA prop and procedural-grass tag settings.
- GTA coordinate placement map, position presets, world-bound checks and approximate overlap warnings.
- gen8 Legacy / gen9 Enhanced target selection.

## Export modes

### Source/conversion package (available in the browser)
The ZIP now contains:
- Tiled visual terrain OBJ files with world-projected UV coordinates and vertex normals.
- MTL material definitions using the selected GunWare material slots.
- Tileable diffuse and normal fallback PNG maps for each selected material.
- GLB preview and 16-bit RAW heightmap.
- A separate coarse collision OBJ intended as the starting point for YBN authoring.
- Material dictionary references, collision metadata, water settings, world bounds, landmarks, vegetation and grass placements.
- A FiveM resource scaffold and conversion checklist.

The source ZIP is **not a finished FiveM map**. OBJ, GLB, RAW and fallback PNGs are not native GTA V RAGE assets.

### Native FiveM package (requires the Windows worker)

The repository now includes a separate worker in [native-worker/](native-worker/). It receives export jobs through the authenticated Next.js proxy, starts Blender in background mode, builds terrain tiles and collisions with Sollumz, and packages the result.

It currently generates:
- Native **YDR** terrain drawables.
- Native **YBN** coarse BVH collisions.
- Native **YTYP** archetypes.
- Native **YTD** texture dictionary.
- A **YMAP CodeWalker XML** containing tile placements, LOD/SLOD hierarchy and configured tree/rock model placements.
- A FiveM resource scaffold, material manifests, water/vegetation metadata and an export report.

**YMAP caveat:** current Sollumz exports YMAP through CodeWalker XML, not as a native binary YMAP. The worker ZIP is therefore marked **nativeReady: false**. Open the XML in CodeWalker, save it as binary .ymap, then run the included finalize-ymap.ps1 from the resource root. Do not start the resource as a complete map before this step.

#### Install and run the worker

Requirements: Windows 10/11 x64, Node.js 20+, Blender 4.0+ (4.5 recommended), Sollumz 2.9.1+ and PyMateria for native Gen8/Gen9 exports, plus CodeWalker for final YMAP conversion.

1. Install Sollumz and PyMateria in the same Blender profile used by the worker.
2. Open PowerShell in native-worker/ and configure the environment variables described in [native-worker/README.md](native-worker/README.md).
3. Start the worker with start-worker.ps1.
4. Configure the web app's .env:

\`\`\`dotenv
ISLAND_EXPORT_BRIDGE_URL=http://WINDOWS_WORKER_LAN_IP:8787
ISLAND_EXPORT_BRIDGE_TOKEN=the-same-long-random-secret
\`\`\`

Keep the worker behind a LAN/VPN/firewall. The HTTP service refuses to start without a bearer token. It runs one Blender conversion at a time and stores temporary jobs under ISLAND_WORKER_DATA.

#### Textures

The supplied GunWare source files contained GTA texture dictionary names, not the original diffuse/normal bitmaps. If you have legally available diffuse/normal replacement images, put them in GUNWARE_TEXTURE_DIR using <material-id>_diffuse.png and <material-id>_normal.png filenames. Otherwise the worker creates procedural fallback maps, packs them into YTD and uses them for the YDR materials. These are fallback textures, not original GunWare/GTA bitmaps.

#### Current limitations

- YMAP binary conversion remains a manual CodeWalker step.
- Native GTA water quads are not produced yet; water settings are included as metadata.
- Grass placement data is retained, but a native YMAP grass batch is not created yet.
- Trees and rocks use built-in GTA model names; verify those archetypes exist in the target game build/custom asset pack.
- Final validation in CodeWalker and on a clean FiveM server is still required.

\`\`\`bash

npm start
\`\`\`

## Deploy

Deploy as a standard Next.js Node.js application. Procedural generation, the 3D viewport and the source ZIP export run in the browser. Native export needs the separate Windows worker. Keep the worker on a private network and configure a long random token.

## Coordinate notes

- One world unit is treated as one metre.
- Export placement uses X/Y world origin and terrain elevation on Z.
- The placement map is indicative; validate actual collisions and overlaps in CodeWalker.
- Large 8–16 km worlds increase CPU, memory, geometry and export costs. Start with a low-resolution test.
